# Jogo de Adivinhação

Esse é um jogo simples que fiz em Python para praticar um pouco de programação.

O computador escolhe um número aleatório entre 1 e 100 e você precisa tentar descobrir qual é. A cada tentativa, ele dá uma dica dizendo se o número é maior ou menor.

## Como executar

Você precisa ter o Python instalado.

No terminal, entre na pasta do projeto e execute:

```bash
python jogo.py
```

## O que pratiquei

- Variáveis
- Condições (`if`, `elif` e `else`)
- Repetição com `while`
- Números aleatórios com `random`
- Tratamento de entrada inválida com `try` e `except`
